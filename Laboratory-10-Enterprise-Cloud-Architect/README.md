# Mission 10: The Enterprise Cloud Architect

## Project Overview

This project deploys a secure multi-tier web application using WordPress and MariaDB with Docker Compose on Ubuntu Server.

## Technologies Used

- Ubuntu Server
- Docker Engine and Docker Compose
- WordPress
- MariaDB
- UFW Firewall
- Bash automation and Cron
