# Final Reflection

From Mission 1 to Mission 10, I learned many things about cloud computing. At first, some tasks were hard for me because I was still learning how the tools and commands worked. There were times when I got errors and had to repeat the steps to make things work. I learned that making mistakes is part of learning, and I should not give up easily.

As I continued with the missions, I became more familiar with setting up systems, using virtual machines, working with servers, and managing applications. In Mission 10, I learned how to use Docker Compose to run WordPress and MariaDB together. I also learned about network settings, firewall rules, backups, and automatic tasks using Cron. These tasks helped me understand how a web application can run on a server and how to keep its data safe.

This journey was not always easy, especially when I had problems with commands and settings. But every problem helped me learn something new. I also realized that cloud computing is not only about making an application work. It is also about keeping it secure, saving important data, and making sure it can run properly. Overall, these ten missions helped me gain more knowledge and confidence. I know I still have a lot to learn, but I can now understand the basics better and use what I learned in future projects.
