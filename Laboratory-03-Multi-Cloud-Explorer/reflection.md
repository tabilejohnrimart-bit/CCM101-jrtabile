# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is Microsoft Azure. I found Azure interesting because of its strong integration with Microsoft technologies and its wide range of cloud services. It provides services for computing, storage, networking, databases, security, and artificial intelligence. I also learned that Azure is a good choice for organizations that already use Microsoft products and services.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide cloud computing services such as virtual machines, storage, databases, networking, security, and other services. They also use global infrastructure with regions and locations that allow organizations to deploy applications closer to their users. Each platform can support different types of workloads and allows resources to scale based on business needs.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when selecting a cloud platform because different organizations have different needs. A startup may prioritize scalability and a wide range of services, while a company using Microsoft technologies may benefit more from Azure. An AI-focused company may prefer GCP because of its AI, machine learning, and Kubernetes capabilities. The best cloud platform depends on the organization's goals, existing technologies, budget, and workload.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about choosing the most popular platform. I learned that I need to understand the client's requirements first and then match those requirements with the appropriate cloud services. I also learned how to compare AWS, Azure, and GCP based on their strengths and services.

## 5. How has your GitHub Cloud Computing Portfolio improved?

My GitHub Cloud Computing Portfolio improved because it now contains organized research, screenshots, cloud platform comparisons, client recommendations, Linux server information, and other documentation. This activity helped me practice using GitHub while also improving my understanding of cloud computing. It also gave me a portfolio that shows my research, technical knowledge, and ability to make cloud platform recommendations.
