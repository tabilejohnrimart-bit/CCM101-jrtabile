# Client Recommendations

Cloud Platform Recommendation Challenge

### Client A – Startup Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a suitable choice for the startup because it provides a wide range of cloud services that can support a mobile application from development to production. The startup can begin with cloud resources that match its limited budget and increase its resources as the application gains more users. AWS also provides services that can support application hosting, databases, and storage. This flexibility can help the startup handle rapid growth without having to build and maintain large physical infrastructure.

**Recommended Services:**

- **Amazon EC2** – Provides virtual servers for running application workloads.
- **Amazon S3** – Provides scalable object storage for application files and data.
- **Amazon RDS** – Provides managed relational databases for application data.
- **AWS Lambda** – Can run application functions without requiring the startup to manage servers.

---

### Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make the migration and management of cloud services easier. The university can use Azure to extend its existing Microsoft environment into the cloud while maintaining identity and access management. This makes Azure a practical choice for a university that wants to migrate some of its services while continuing to use its existing Microsoft technologies.

**Recommended Services:**

- **Azure Virtual Machines** – Can host Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides identity and access management for users and applications.
- **Azure Blob Storage** – Provides scalable storage for documents, backups, and other data.
- **Azure Virtual Network** – Provides private networking for Azure resources.

---

### Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a strong choice for the AI research company because it provides services and infrastructure designed for artificial intelligence and machine learning workloads. The company requires high-performance computing, and Google Cloud provides computing resources that can be used for demanding workloads. Google Cloud also provides AI and machine learning services that can support the development and deployment of intelligent applications. Its support for Kubernetes and cloud-native technologies can also help the company manage scalable AI applications.

**Recommended Services:**

- **Compute Engine** – Provides virtual machines for high-performance computing workloads.
- **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized applications.
- **Vertex AI** – Provides tools and services for developing and deploying AI and machine learning applications.
- **Cloud Storage** – Provides scalable storage for datasets, models, and research files.

---

### Client D – Global E-Commerce Company

**Recommended Platform: Amazon Web Services (AWS)**

AWS is a suitable choice for the global e-commerce company because it provides global cloud infrastructure and services that can support highly available applications. An international e-commerce platform needs to serve customers in different locations while maintaining performance and availability. AWS provides services for automatic scaling, load balancing, computing, databases, and content delivery that can help support this type of workload. These capabilities allow the company to handle changes in customer traffic and support a globally distributed online shopping platform.

**Recommended Services:**

- **Amazon EC2** – Provides scalable computing resources for running the e-commerce application.
- **Elastic Load Balancing** – Distributes incoming traffic across application resources.
- **Amazon EC2 Auto Scaling** – Automatically adjusts computing capacity based on demand.
- **Amazon CloudFront** – Delivers web content to users through a global content delivery network.
- **Amazon RDS** – Provides managed relational database services for e-commerce data.
