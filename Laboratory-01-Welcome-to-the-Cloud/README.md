# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity introduces the basic skills needed by a cloud infrastructure engineer. The activities include working with a Linux environment, gathering system information, organizing files and directories, creating a GitHub repository, and documenting technical work using Markdown.

## Objectives
- Access and use a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Practice documentation skills used by cloud professionals.

## Activities Performed
- Accessed the Ubuntu Linux environment through KillerCoda.
- Created and logged in to a new Linux user account.
- Gathered Linux system information.
- Created and organized directories and Markdown files.
- Created a public GitHub repository for the Cloud Computing portfolio.

## Linux Commands Used
- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname.
- `ls` – lists files and directories.
- `mkdir` – creates directories.
- `cd` – changes the current directory.
- `cat` – displays the contents of a file.
- `nano` – creates or edits text files.

## Skills Learned
Through this laboratory activity, I learned how to work with a cloud-based Linux environment, navigate directories, gather system information, create and organize files, and use GitHub to maintain a professional Cloud Computing portfolio.
